# 前端页面全表与逻辑入口

下面的“页面逻辑”按 route → feature → API/query → 用户动作说明。route 文件是当前源码入口，实际表格/表单请继续打开同名 feature 目录。

## 公开页面与认证页

| 路由文件 | 页面职责 | 主要逻辑 |
| --- | --- | --- |
| `routes/index.tsx` | 首页/入口 | 根据系统状态和登录态导航 |
| `(auth)/sign-in.tsx` | 登录 | 表单校验、登录、session 写入、失败提示 |
| `(auth)/sign-up.tsx`、`register.tsx` | 注册 | 注册字段、验证码/邀请、成功后登录或跳转 |
| `(auth)/forgot-password.tsx`、`reset.tsx` | 找回密码 | 申请、token 校验、重置提交 |
| `(auth)/otp.tsx` | OTP | 一次性验证码校验和登录继续 |
| `(auth)/oauth.tsx`、`oauth/$provider.tsx` | OAuth | provider 回调、错误和 session 建立 |
| `setup/index.tsx` | 首次安装 | 初始化管理员和系统配置 |
| `pricing/index.tsx`、`pricing/$modelId/index.tsx` | 公开价格 | 查询模型/价格并展示详情 |
| `about/index.tsx`、`privacy-policy.tsx`、`user-agreement.tsx` | 静态信息 | 系统设置文案和 Markdown/HTML 内容 |

## 普通用户页面

| 路由文件 | 业务模块 | 逻辑代码入口 |
| --- | --- | --- |
| `_authenticated/dashboard/$section.tsx` | 仪表盘 | `features/dashboard/`：section registry、统计 query、图表 |
| `_authenticated/playground/index.tsx` | 在线调试 | `features/playground/`：模型选择、消息状态、流式请求、停止和历史 |
| `_authenticated/chat/$chatId.tsx` | 会话 | `features/chat/`：chat id、消息列表、流式增量和重试 |
| `_authenticated/channels/index.tsx` | 渠道管理 | `features/channels/`：列表、筛选、创建/编辑、测试渠道 |
| `_authenticated/models/index.tsx`、`models/$section.tsx` | 模型/价格 | `features/models/`：能力、映射、价格和可用性 |
| `_authenticated/keys/index.tsx` | API Keys | `features/keys/`：创建、复制、撤销、scope 和过期 |
| `_authenticated/wallet/index.tsx` | 钱包/充值 | `features/wallet/`：余额、充值、支付、订阅和账单 |
| `_authenticated/subscriptions/index.tsx` | 订阅 | 计划展示、购买、当前订阅和取消 |
| `_authenticated/redemption-codes/index.tsx` | 兑换码 | 输入、兑换、结果和历史 |
| `_authenticated/profile/index.tsx` | 个人资料 | 用户资料、语言、主题和偏好 |
| `_authenticated/security/index.tsx` | 安全 | 密码、2FA、Passkey、session 管理 |

## 管理员页面

| 路由文件 | 业务模块 | 逻辑 |
| --- | --- | --- |
| `_authenticated/users/index.tsx` | 用户管理 | 搜索、角色/分组、额度、禁用和详情 |
| `_authenticated/usage-logs/index.tsx`、`$section.tsx`、`audit.tsx` | 使用/审计日志 | 分页、筛选、详情、导出和审计字段 |
| `_authenticated/system-info/index.tsx` | 系统信息 | 版本、环境、运行状态和诊断 |
| `_authenticated/system-settings/index.tsx` | 设置入口 | 分发到各设置 section |
| `system-settings/site/*` | 站点 | 名称、Logo、公告、注册开关 |
| `system-settings/auth/*` | 认证 | 登录、OAuth、Session、MFA 配置 |
| `system-settings/billing/*` | 计费 | 价格、倍率、充值/支付配置 |
| `system-settings/models/*` | 模型 | 模型能力、价格和映射 |
| `system-settings/operations/*` | 运维 | 缓存、任务、日志和系统操作 |
| `system-settings/content/*` | 内容 | 公告、协议和展示内容 |
| `system-settings/security/*` | 安全 | 风险策略、代理和安全参数 |
| `system-settings/request-policies/*` | 请求策略 | 敏感词、重试、拒绝和审计规则 |
| `_authenticated/task-plugins/index.tsx` | 插件 | 插件列表、安装、启停、配置和任务状态 |

## 错误和布局

`(errors)/401.tsx`、`403.tsx`、`404.tsx`、`500.tsx`、`503.tsx` 是公共错误页；`_authenticated/errors/$error.tsx` 是登录后业务错误页。`__root.tsx` 和 `components/layout` 负责全局 meta、主题、导航、错误边界和 Outlet。
